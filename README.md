# Solar Power Performance Dashboard
## Project Overview
This project presents an interactive Solar Power Performance Dashboard developed using Microsoft Power BI.
The dashboard provides a visual overview of solar power generation and performance-related metrics, including DC power, AC power, daily yield, total yield, irradiation, and temperature.

## Dashboard Objectives
The main objectives of this dashboard are to:
- Analyze daily solar power yield
- Monitor AC and DC power over time
- Analyze daily irradiation levels
- Track yield by source key
- Analyze ambient temperature trends
- Analyze module temperature trends
- Provide interactive filtering for the dashboard data

## Key Dashboard Metrics
The dashboard includes the following performance metrics:
- Total DC Power
- Total AC Power
- Total Daily Yield
- Total Yield
- Average Ambient Temperature
- Average Module Temperature

## Dashboard Visualizations
### Daily Yield Over Time
Shows the daily yield trend across the available days.

### AC Power Over Time
Displays AC power values over time and allows the variation in AC power to be viewed across the available dates.

### DC and AC Power by Day
Compares the daily sum of DC power and AC power.

### Irradiation by Day
Shows the daily irradiation trend across the available period.

### Total Yield by Source Key
Displays total yield grouped by source key.

### Ambient Temperature by Day
Shows the variation in ambient temperature across the available days.

## Interactive Filters
The dashboard provides interactive filters for:
- Date
- Plant ID
- Source Key
These filters allow users to explore the dashboard data based on different dates, plants, and source keys.
